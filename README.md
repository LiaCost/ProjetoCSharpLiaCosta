📚 ProjetoCSharp - Estudos e Exercícios em C#
Este repositório contém uma série de arquivos desenvolvidos para estudar e praticar os principais conceitos da linguagem C#. A ideia é explorar desde o básico até tópicos mais avançados, com exemplos práticos e bem organizados.

🧠 Conteúdos Abordados
-✅ Entrada e saída de dados
-✅ Tipos primitivos
-✅ Operadores (aritméticos, lógicos, atribuição, comparação, ternário)
-✅ Conversão de tipos
-✅ Condicionais e laços de repetição
-✅ Arrays, Listas e Coleções
-✅ Tratamento de exceções
-✅ Programação orientada a objetos
-✅ LINQ
-✅ Recursão
-✅ Escopo de variáveis, tipos var e dynamic
-✅ Structs, Enums, Nullable
-✅ Parâmetros por referência e por valor

🎯 Objetivo
Este projeto tem como foco servir de material de estudo para quem está aprendendo ou revisando conceitos da linguagem C#, com exemplos claros e divididos por tema.
