📚 ProjetoCSharp - estudos e exercícios em C#:
Este repositório contém uma série de arquivos desenvolvidos para estudar e praticar os principais conceitos da linguagem C#. A ideia é explorar desde o básico até tópicos mais avançados, com exemplos práticos e bem organizados.

🧠 Conteúdos Abordados: Entrada e saída de dados, tipos primitivos Operadores (aritméticos, lógicos, atribuição, comparação, ternário), conversão de tipos, condicionais e laços de repetição, arrays, listas e coleções, tratamento de exceções, programação orientada a objetos, LINQ, recursão, escopo de variáveis, tipos var e dynamic, structs, enums, nullable, parâmetros por referência e por valor.

🎯 Objetivo: Este projeto tem como foco servir de material de estudo para quem está aprendendo ou revisando conceitos da linguagem C#, com exemplos claros e divididos por tema.
